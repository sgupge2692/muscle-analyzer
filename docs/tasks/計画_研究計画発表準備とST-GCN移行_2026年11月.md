### 1-3. 質疑対応準備

v18 の限界記載から，以下の想定問答を用意する：

- 角度別定量点が n=3 であり，相関が統計的に有意でない（p>0.05）ことの制約説明
- スクワット大臀筋 r=0.17 の原因（文献の非対称な角度−活動度パターンを対称ガウスで表現できない限界）と，非対称パラメータを逆算して相関を改善する案を**過学習のために見送った経緯**（これ自体を方法論的知見として説明する）
- デッドリフトの参照値（Moreira et al., 2023）が等尺性条件であり動的動作と条件が異なる限界
- 自らEMGを実測しない理由（倫理審査・被験者確保・機材調達をスコープ外とする v18 の方針）
- 検証不可の3組み合わせ（デッドリフト大臀筋，スクワットハムストリング，スクワット脊柱起立筋）の理由（対応する角度別定量値を持つ公開文献が不在）

## マイルストーン2: 2027年4〜6月 ST-GCN移行・文献較正确映の再学習・MVP完成

### 2-A. ST-GCN移行（4月）

- `backend/src/ml/train_stgcn.py` を用いて ST-GCN を学習し，1D-CNN と同一の評価分割で F1 を比較する
- 比較条件: ルールベースのみ／1D-CNNのみ／ST-GCNのみ／ハイブリッド（v18 の評価方法の3条件比較に ST-GCN を加えた構成）
- **移行完了の判断基準**: 「F1 micro 0.93 以上を満たすモデル構成が得られること」。1D-CNN と ST-GCN のどちらであっても，基準を満たせば MVP に採用してよい
- **逃げ道**: ST-GCN が明確に劣る場合は 1D-CNN を継続する（無理に ST-GCN に固執しない）。判断は F1 比較の実測値に基づき，`docs/muscle_mapping_review.md` 等ではなく本計画の結果メモに記録する
- ハイパーパラメータは val_seen でのみ選択し，test_seen での評価は最終評価として1回のみ（v18 のルールを踏襲）

### 2-B. 文献較正結果を反映したハイブリッドモデル再学習（5月）

- v18 記載の較正結果（スクワット大腿四頭筋等の高整合結果と，スクワット大臀筋の低整合の限界）を反映した，種目別基準重み・角度−活動度関数の状態をルールベース側に確定させ，ハイブリッドモデルを再学習する
- 低整合（スクワット大臀筋）は「対称ガウス関数の限界」として限界報告の対象に維持し，パラメータの逆算による改善は行わない（v18 の方針）
- 再学習後，test_seen で最終評価を1回のみ実施し，F1 micro 0.93 以上を確認する

### 2-C. Webアプリの最小実用版（MVP）完成（6月）

v18 §2.1〜§2.3 に基づき，以下が一通り動作する状態を完成とする：

- **動画アップロードモード**: 動画アップロード → MediaPipe 骨格検出（33点3D座標） → 関節角度・角速度・左右非対称性等38特徴量 → レップ自動検出 → ハイブリッド推定 → 20筋群ヒートマップ → 逸脱フレームの特定とフォームフィードバック
- **リアルタイムモード**: カメラ映像 → 骨格と筋肉活動のオーバーレイ表示
- **3Dアバターは MVP の実装スコープに含めない**（フィードバックはテキストまで。3Dアバターは v18 最終章の将来の発展課題として位置づけ続ける）

### 完了条件

- [ ] F1 比較実験（2-A）の結果が記録され，0.93 以上のモデル構成が確定している
- [ ] 較正結果反映の再学習（2-B）後の最終評価が実施され，F1 micro 0.93 以上が確認されている
