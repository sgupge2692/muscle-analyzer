## 新規性主張の再検証結果（本再適用の主目的）

- **4条件合取の主張は成立**: MYoACT（筋活動3D可視化を主張するプロ向けWeb）と CueForm AI（RPE入力つきフォーム解析）を競合に追加した後も，「①単眼，②リアルタイム，③筋活動の連続値，④手法と検証の公開，を同時に満たす出荷済みスマホアプリは2026年11月13日時点で確認されていない」は維持できる。v16 本文に両製品を追加済み（ID-010, ID-011）。
- **RPE統合（将来課題）の精緻化**: Metric Lift が2026-03に RPE/RIR 記録を搭載し，乖離時の動画確認を手動ガイドしているため，「RPEを記録する」は新規性にならない。v16 の最終章に「乖離の自動診断＋筋活動推定統合を差別化」と補足済み（ID-024）。
- **エビデンスレベル表示の精緻化**: CueForm AI が findings に信頼度（confidence level）を付与するため，「検出結果に信頼度を表示」は新規性にならない。差別化は文献由来の証拠階層（literature_validated / literature_derived / literature_referenced / model_estimate）。v16 の新規性第四には本件の補足が未反映 → 提出前に一文追加を推奨（ID-030）。
- **事前実験値の反映**: F1比較実験（`backend/scripts/evaluate_f1_comparison.py`，結果 `backend/output/f1_comparison_test.csv`）の実測値（ルール0.82 / 1D-CNN 0.96 / ハイブリッド0.97，test_seen 1,458サンプル）を想定する結果に反映済み（ID-022）。文献較正の現状（Quadriceps r=0.9988，Gluteus r=0.1698，n=3）は `backend/output/literature_validation_summary.csv`。
