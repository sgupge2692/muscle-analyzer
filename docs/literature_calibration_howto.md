# 文献較正パイプラインの手順書（how-to）

**版**: 1.0（2026年11月15日）
**対象**: ウェイト種目の筋群活動推定に対して，公表EMG文献の角度−活動度関係を数値参照として用いて較正・検証する手順
**実装の所在**: `backend/src/anatomy/muscle_activation.py`（`EXERCISE_BASE_WEIGHTS`, `_angle_position_modifier`, `_literature_position_modifier`），`backend/src/anatomy/literature_emg_curves.json`，`backend/scripts/literature_validation.py`，記録先は `docs/muscle_mapping_review.md`

---

## 1. 目的と適用条件

本手順は，「実測EMGの新規収集を伴わずに，公表されたEMG研究の角度−活動度関係を定量的な参照値として較正・検証する」サイクルを，新しい種目・筋の組み合わせに適用するための手順である。

**適用条件（これを満たすペアのみ実行する）**:

- 対象（種目, 筋群）について，**角度位置ごとの定量値**（%MVC / %MVIC 等の数値表・グラフ）を本文中に公表している文献が存在する
- 文献の測定条件（等尺性/動的，負荷，被験者）が明記されている
- 筋群の同定が可能である（文献の測定筋とシステムの筋群名の対応がつける）

定量値が存在しない（種目, 筋群）ペアは**検証を行わない**。集計%MVICに基づく基準重みの設定のみを行い（手順①），エビデンスレベルを「未検証」として区別する。

## 2. 禁止事項（厳守）

1. **検証データからのパラメータ逆算禁止**: `peak_angle_deg` / `width_deg` を，検証に使う data_points からフィッティング・逆算してはならない。パラメータは検証データとは**独立した根拠**（文献の位置定義・定性記述・他文献・解剖学的妥当性）から事前指定し，その根拠をメモに記録する
2. **根拠なき数値の埋め込み禁止**: 文献に明記されていない数値を「それらしい値」として採用しない。目視読取による近似値の場合は，その旨をコメントで明記する（例: 「論文 Fig.2 から目視で読み取った近似値」）
3. **不一致時の安直な再較正禁止**: 低整合が検出された場合でも，パラメータの再フィッティングによって相関を改善する対応は行わない（過学習）。修正には独立した根拠が必要であり，なければ限界として記録する
4. **角度規約の変換忘れ禁止**: 文献が膝屈曲角（伸展=0°）で報告する場合，システムの解剖学的角度（直立=180°）への変換（180−屈曲角）を必ず行う

## 3. 手順

### 手順①: 種目別基準重みの設定（対象: 種目単位）

1. 文献から運動全体の平均%MVIC（または等価な集計値）を種目・筋ごとに収集する（例: Escamilla et al. 2002, Martín-Fuentes et al. 2020）
2. `muscle_activation.py` の `EXERCISE_BASE_WEIGHTS` に重みを追加する。正規化後の比率が文献値の比率と大きく外れない値にする
3. **実装**: 重みの採用根拠（文献値・正規化後の値・変換計算）を `docs/muscle_mapping_review.md` に記録する
4. **注意**: 重み追加は正規化後の他筋の値をシフトさせる。レスポンスのスキーマは不変だが数値が変化する旨を記録する

### 手順②: 角度−活動度関係の数値化（data_points）

1. 文献本文中の角度別定量値（数値表・Δ%・区間比較）を `literature_emg_curves.json` の `data_points` に追加する
2. 角度はシステム規約に変換する（屈曲角→180−屈曲角）
3. 3点以下の小数点は文献記載のまま。導出値（Δ%からの算術導出）の場合は導出式をメモに残す
4. **実装**: 各 data_points に出典（論文・表・図）を note として記録する

### 手順③: ガウスパラメータの事前指定

1. `peak_angle_deg`: 文献が明記する活動最大位置。不明の場合は**null のまま**とし，角度位置変調を適用しない（フォールバックが自動で効く）
2. `width_deg`: 文献に明記されていないため，既存ペアと同一の事前指定値を用いる（現行: Quadriceps 35, Gluteus/Lower_Back 50）。根拠と採用値をメモに記録する
3. **検証データ（手順②の data_points）から逆算した場合は手順全体を無効とする**

### 手順④: 検証の実行

```bash
cd backend && python scripts/literature_validation.py
```

- 正解 = `data_points`，予測 = 対称ガウス関数（peak/width を事前指定値で固定）
- 出力: Pearson r，p，正規化最大誤差（`backend/output/literature_validation_summary.csv`）

### 手順⑤: 判定と不一致時の対応

| 判定 | 基準（目安） | 対応 |
|---|---|---|
| 高整合 | r ≥ 0.98（正規化最大誤差小） | 報告対象。ただし n=3 の参考値として記録 |
| 部分整合 | 0.6 ≤ r < 0.98 | 構造原因（例: 文献の非単調パターン vs 対称ガウスの減衰）を特定して記録 |
| 低整合 | r < 0.6 | 原因分析（関数の対称性・条件差・文献のばらつき）→ 修正には独立根拠が必要。なければ限界として記録 |
| 検証不可 | 角度別定量値が公表されていない | 検証を行わない。「本調査で参照した文献の範囲では確認できず」と調査範囲を明示して記録する |

不一致の対応順序: (1) 構造原因の特定（例: 文献の非対称パターン），(2) 修正案が検証データと**独立した根拠**を持つか評価，(3) 持たなければ**現状維持＋限界の記録**（前例: Squats/Gluteus における非対称ガウス拡張の実施→取り下げ，コミット 57cc9df）

### 手順⑥: 記録と evidence_level への反映

1. 結果（n，r，p，正規化最大誤差，判定，原因分析）を `docs/muscle_mapping_review.md` に表形式で追記する
2. data_points が非nullかつ検証済みのペア → 「文献較正済み」，集計%MVICから導出 → 「文献値導出」，基準重み・文献なし → 「未検証」（`backend/src/anatomy/evidence_level.py` が自動判定）

## 4. テンプレート（muscle_mapping_review.md 追記用）

```
## 文献較正の実装（YYYY-MM-DD）: [種目]/[筋群]

### 文献調査の経緯
| 文献 | 角度別定量値の有無 | 結論 |
|---|---|---|
| [著者 et al. 年（誌名，アクセス可否）] | [あり（表/Δ%）/定性のみ/なし] | [採用/転記不可/検証不可] |

### literature_emg_curves.json への追加内容
- data_points: [角度]:[値], ...（角度規約変換の明記）
- peak_angle_deg: [値またはnull]（根拠: ...）／width_deg: [値]（根拠: 事前指定）

### 検証結果
| n | r | p | 正規化最大誤差 | 判定 |
|---|---|---|---|---|

### 解釈上の注意
1. n=3 の相関は参考値（p値は非有意になる点数であることに留意）
2. 条件差（等尺性/動的）の明記
3. 構造原因の特定と，修正しない場合の理由
```

## 5. 既知の落とし穴

- **n=3 の統計的制約**: df=1 のため p<0.05 には r≥0.997 が必要。r は記述的効果量として報告し，p値を主役にしない（論文の説明は `docs/tasks/文献較正限界の検討_2026年11月.md` §2 を参照）
- **等尺性 vs 動的**: 参照文献が等尺性測定の場合，動的動作との条件差を限界として明記する（前例: Moreira et al. 2023）
- **角度規約**: 屈曲角（0°=伸展）と解剖学的角度（180°=直立）の混在。変換忘れは全ての整合判定を無効化する
- **二値分類系の文献は不可**: 「使用/未使用」のみの文献（例: MuscleMap/TransM³E系）は連続値の較正には使えない
- **非単調な角度−活動度パターン**: 文献が非単調パターン（例: 大臀筋は20°≈90°で140°で急減）を報告する場合，対称ガウスでは表現できず低整合になる。非対称パラメータの逆算は禁止（§2-1）
- **複数部位の平均**: 文献が同一筋群の複数部位（VL/VM/RF 等）を別々に報告する場合，採用する部位と平均の有無を明記する
